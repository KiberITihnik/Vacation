# Вакансии для двоих — Telegram-бот

Дважды в день (09:00 и 18:00 по Челябинску) бот собирает свежие вакансии, отбирает их под
два профиля и присылает каждой свою подборку в Telegram:

* **girlfriend** — Челябинск (офис/гибрид) или удалёнка, без опыта, сортировка по зарплате;
* **sister** — только удалёнка, тексты: копирайтер, редактор, SMM и т.п.; фриланс отдельным блоком.

Бот **не откликается** за вас: он присылает ссылку, отклик вы делаете сами на сайте.

## Установка

Нужен компьютер или VPS, на котором открываются российские сайты (trudvsem.ru, superjob.ru)
и Telegram, с установленным Docker.

### 1. Создать бота
1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя и логин.
2. BotFather пришлёт токен вида `123456:ABC...` — это `TELEGRAM_BOT_TOKEN`.

### 2. Скачать проект и заполнить настройки
```bash
git clone <адрес репозитория> job-alerts && cd job-alerts
cp .env.example .env
cp config/profiles.example.yaml config/profiles.yaml
nano .env          # вставьте TELEGRAM_BOT_TOKEN
```

### 3. Проверить источники (этап 0)
```bash
python3 scripts/recon.py
```
Скрипт покажет, что открывается с вашей машины, и сохранит настоящие ответы API
в `tests/fixtures/recon_*.json`. Пришлите вывод разработчику, если что-то `ERR`.

### 4. Узнать chat_id
1. Запустите бота: `docker compose up -d --build`.
2. Напишите боту `/start` со своего аккаунта. Пока `ADMIN_CHAT_ID` пуст, бот ответит
   «Это частный бот» и запишет chat_id в лог: `docker compose logs | grep chat_id`.
   Ещё проще: напишите **@userinfobot**, он покажет ваш id.
3. Впишите свой id в `ADMIN_CHAT_ID`, перезапустите (`docker compose restart`).
4. Теперь пусть девушка и сестра напишут боту `/start` — бот пришлёт вам их chat_id.
   Впишите их в `GIRLFRIEND_CHAT_ID` и `SISTER_CHAT_ID`, снова `docker compose restart`.

### 5. Почта для hh.ru (этап 3, пока не нужно)
API поиска hh.ru закрыт, поэтому вакансии с hh.ru будут приходить через письма «Автопоиска»:
1. Заведите отдельный ящик, например `vacancies.bot@yandex.ru`.
2. Включите в настройках почты доступ по IMAP и создайте **пароль приложения**.
3. Заполните `IMAP_HOST` (`imap.yandex.ru`, `imap.gmail.com`, `imap.mail.ru`), `IMAP_USER`,
   `IMAP_PASSWORD`.
4. Девушке и сестре — каждая в своём аккаунте hh.ru:
   * **девушка:** поиск «менеджер по продажам OR администратор OR ассистент OR оператор»,
     регион Челябинск, «Опыт работы: нет опыта», «Уровень дохода: от 50 000»,
     ещё один поиск с теми же словами и «Формат работы: удалённо» без региона;
   * **сестра:** «копирайтер OR редактор OR контент-менеджер OR SMM OR корректор»,
     «Формат работы: удалённо», опыт «нет опыта» и «от 1 до 3 лет», доход от 40 000.
   * Нажать «Сохранить поиск» → «Присылать новые вакансии на почту» → раз в день.
   * В настройках уведомлений hh.ru указать почту бота или настроить пересылку писем
     от `noreply@hh.ru` на неё.

### 6. Ключ SuperJob (этап 3, пока не нужно)
Зарегистрируйте приложение на https://api.superjob.ru → «Зарегистрировать приложение»,
скопируйте Secret key в `SUPERJOB_APP_KEY`.

### 7. Запуск
```bash
docker compose up -d --build
docker compose logs -f          # логи в реальном времени
```
Логи также пишутся в `logs/job-alerts.log`, база — `data/jobs.db`.

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | приветствие и привязанный профиль |
| `/now` | подборка прямо сейчас (не чаще раза в 30 минут) |
| `/top` | 10 лучших за последние 7 дней |
| `/pause`, `/resume` | пауза и возобновление рассылки |
| `/minsalary 60000` | своя минимальная зарплата |
| `/stats` | (админ) статистика запусков и ошибок |

Кнопки под карточкой: 👍 и ✅ сохраняются; 👎 опускает похожие вакансии ниже;
🚫 «Скрыть компанию» убирает компанию из следующих подборок.

## Как менять критерии

Всё в `config/profiles.yaml`: города, ключевые слова, стоп-слова, минимальная зарплата,
слова антискам-фильтра, веса сортировки, время рассылки. После правки:
`docker compose restart`.

Проверить подборку без отправки:
```bash
docker compose run --rm job-alerts python -m app.pipeline --dry-run --profile sister
```

## Для разработчика

```bash
python3.12 -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
pytest
ruff check . && mypy --strict app/processing
```

Новый источник — один файл в `app/sources/` с классом, у которого есть `name`,
`async fetch(profile) -> list[Vacancy]` и `async aclose()`, плюс строка в
`REGISTRY` (`app/sources/__init__.py`) и секция в `sources:` конфига.
